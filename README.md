# 폴란드 교양강의

첫 여행자를 위한 폴란드 강의 핸드아웃 패키지. **정규 10회 + 특설 2강 = 강의 12개.**

- 웹: <https://jamyungkoo.github.io/poland-lecture/>
- 오프라인: 폴더를 통째로 내려받아 `index.html`을 브라우저로 열면 됩니다. 외부 의존성이 없어 인터넷 없이 그대로 동작합니다.

|---|---|---|---|

아우슈비츠를 깊이 들어가는 두 강의. 정규 시리즈와 독립적으로 볼 수 있게 자급자족으로 씌어 있습니다 (사전 지식 불필요).

| | 제목 | 내용 | 파일 |
|---|---|---|---|
| 특설 1 | 아우슈비츠로 가는 길 — 1939년 9월에서 1942년 1월까지 | 그 자리가 가능해지기까지의 28개월. 폴란드 침공부터 반제 회의까지 | `special-01-ww2-ghetto.html` |
| 특설 2 | 아우슈비츠 — 한 자리에서 일어난 모든 것 | 1940년 6월 14일 첫 입소부터 1945년 1월 27일 해방까지 4년 7개월 | `special-02-auschwitz.html` |

## 두 가지 시안

- **시안 A · 읽기 핸드아웃** (모든 회차) — 교양서 스타일의 정적 페이지. 좌측 sticky 미니목차, Beat 단위 설계(리드인 → 이미지 → 본문 → 정리).
- **시안 B · 인터랙티브 슬라이드** (1회차만) — 한 뷰포트 고정, `→` / `Space`로 진행. 23슬라이드. 2회차 이후는 시안 A 단일 트랙으로 통일했습니다. `01-introduction-interactive.html`

```
   ├─ css/  base.css      디자인 토큰 · 베이스 · 공통 컴포넌트
   │        handout.css   시안 A 전용 (Beat, 미니목차, 정거장 등)

   │        index.css     메인 인덱스 전용

   └─ images/  01–10 · special-01 · special-02   회차별 이미지 + credits.txt
```

## 기술 사양

- **외부 의존성 0** — CDN 없음, 폰트 파일 없음, 빌드 없음. 정적 HTML 그대로 배포·열람
- 시스템 폰트 (Apple SD Gothic Neo / Pretendard / Noto Sans KR)
- 이미지 114개 전부 동봉
- ES2018+ 표준 JS (`deck.js` 하나뿐)
- 반응형 — 모바일·태블릿 폭에서 자동 1단 레이아웃

## 이미지 출처

모든 이미지는 Wikimedia Commons에서 받았고 라이선스는 CC BY-SA 또는 Public Domain입니다.
회차별 정확한 출처는 `assets/images/<회차>/credits.txt`.

## 인쇄용 PDF

`pdf/`에 1회차와 6회차 PDF가 들어 있습니다. 나머지 회차는 아직 없고, `index.html`에서도 링크하지 않습니다. 필요하면 브라우저 인쇄(⌘P)로 뽑는 편이 빠릅니다.

## 실제 여행 시 유의

- 투어 회차(6·8·10)의 입장료·운영시간·교통편·환율은 시기별로 바뀝니다. 출발 직전 공식 사이트 확인 권장.
- 박물관 일부는 월요일·화요일 휴무가 있으니 일정 확인.
- 도보 코스는 편한 신발 + 물.
